# 二、逐页详细内容

## 第 1 页：研究背景、相关工作与研究空白

标题：从 Action-centric VLA 到 Selective Multi-stream Predictive VLA

这一页应该首先明确：我们的研究并不是单纯追求多模态输出，也不是简单地将 Action Chunk 并行化，而是希望同时实现两个能力。

### 1. 现有 VLA 的两个局限

局限一：多模态预测缺少真正的时间并行机制

很多 VLA 将不同模态组织在同一自回归序列中，即使包含任务语义、空间信息和动作信息，也可能需要按序生成。

局限二：并行预测不等于选择性生成

一些工作已经能够一次性预测多个未来时间位置，甚至并行预测多个输出，但这不意味着模型能够在推理时灵活决定只生成 Action、Action + Point Track，或者其他组合。

### 2. 相关工作对比

建议使用二维分类表，避免笼统地说现有工作都没有实现并行预测。

| 代表工作    | 预测机制           | 已有能力                         | 与我们的差异                                        |
| ----------- | ------------------ | -------------------------------- | --------------------------------------------------- |
| OpenVLA     | 自回归             | 统一序列建模                     | 传统逐 Token 生成                                   |
| G0.5        | 自回归多任务       | 推理与动作统一生成               | 仍是单一 AR Stream                                  |
| ModAR       | 模态自回归         | 多种空间模态参与动作预测         | 不同模态依次生成                                    |
| π0.5        | Flow Matching      | Action Chunk 连续生成            | 没有统一的异构 Primitive 按需解码                   |
| OpenVLA-OFT | Parallel Decoding  | 多时间位置 Action 一次前向       | 主要针对 Action Chunk                               |
| MMaDA-VLA   | Parallel Diffusion | 联合生成目标观测与 Action        | 未建立我们的 Primitive 选择式解码机制               |
| VFlash      | Parallel Drafting  | 完整 Visual Primitive 一次 Draft | 重点是 Primitive Drafting，不等于统一的多流 TD 架构 |

这里需要注意几个学术表述细节：

- OpenVLA-OFT 已经能够通过双向 Action Embedding 并行预测整个 Action Chunk，不能把它描述成完全没有时间并行。
- π0.5 使用 Flow Matching Action Expert 生成连续动作，也已经具有 Chunk 级并行生成能力。
- MMaDA-VLA 已经实现了 Action Chunk 与目标观测的联合并行去噪，因此也不能声称此前没有跨模态并行生成。
- VFlash 更值得重点讨论：它已经支持根据 Primitive 类型和请求长度构造预测 Block，并用轻量 Drafting Transformer 一次预测完整 Primitive。因此不能忽略它的先例，也不应该把简单的 Primitive Parallel Drafting 当作我们的独立创新。

### 3. 我们真正希望解决的问题

## 两个核心能力的交集

A. Temporal / Primitive Parallelism

在统一架构中，能够并行预测不同时间位置及不同 Primitive。

B. Selective Primitive Generation

推理时能够选择 Action、Point Track、Subtask 的任意有效组合，并避免计算未选中的分支。

TD-VLA

时间并行 + 多流联合预测 + 按需生成

本页结论： 现有工作已经分别探索了 Action 时间并行、跨模态并行以及 Primitive Drafting，但我们希望研究的是一个能够统一处理异构 Primitive、支持不同生成范式和选择性推理的 VLA 架构。

## 第 2 页：TD-VLA 核心创新与总体架构

标题：Temporal-Depth VLA：面向异构 Primitive 的双维度预测架构

这一页明确提出我们的研究方案。

### 1. 核心架构

- Shared VLM Backbone：提供视觉、语言和机器人状态的共享上下文。
- Temporal Modeling：在时间维度建模历史信息与未来演化。
- Depth / Primitive Modeling：建模 Action、Point Track、Subtask 之间的关系。
- Primitive-specific Decoder：根据不同 Primitive 的数据类型进行预测。
- Selective Generation：通过配置预测目标控制实际激活的解码分支。

### 2. 加入 VFlash 的 Drafting 思想

VFlash 提供一个非常值得借鉴的技术机制：

- 通过 Primitive 类型确定预测结构。
- 通过 Primitive 长度确定 Drafting Slot 数量。
- 使用非因果 Transformer 一次并行预测完整 Primitive。
- 避免对每个坐标或 Token 进行串行自回归生成。

在我们的架构中，可以进一步扩展：

| VFlash 的思路                | TD-VLA 的扩展                  |
| ---------------------------- | ------------------------------ |
| Primitive-start token        | Primitive Selection / Start    |
| Dynamic block layout         | 异构 Primitive Slot Layout     |
| One-pass primitive drafting  | 多 Primitive Global Drafting   |
| Spatial primitive prediction | Action + Point Track + Subtask |
| Primitive-specific layout    | 按需激活不同 Primitive Decoder |

这里要特别强调：VFlash 是我们借鉴 Drafting 机制的重要先例，而不是 TD-VLA 本身。

## 第 3 页：Multi-stream 表示与异构时间结构

标题：Heterogeneous Primitive Streams：不同语义、不同时间尺度

这一页回答模型究竟要预测什么。

### 1. 三个核心 Primitive

| Stream         | 预测内容               | 语义层次 | 时间特征       |
| -------------- | ---------------------- | -------- | -------------- |
| A: Action      | 机器人未来动作         | 执行层   | 高频、连续     |
| P: Point Track | 物体与关键点的未来轨迹 | 空间层   | Chunk 级       |
| S: Subtask     | 当前子任务及任务事件   | 任务层   | 低频、事件驱动 |

### 2. 统一的多流表示

定义：

$ Z_t=\{A_t,P_t,S_t\} $

其中三个 Stream 不一定在每个时间窗口都需要产生新 Token。

增加有效性 Mask：

$ M_t^k\in\{0,1\},\quad k\in\{A,P,S\} $

例如：

- Action：每个时间窗口都有预测。
- Point Track：与 Action Horizon 对齐。
- Subtask：只有发生 START、UPDATE、DONE 等事件时才产生新的事件 Token。

### 3. 为什么需要异构时间建模？

不能简单地把三个模态当成相同频率的三个输出头。

- Action 与 Point Track 有较强的空间和时间关联。
- Subtask 表示任务状态，具有事件驱动属性。
- 如果强制每个时间窗口都生成 Subtask，可能产生大量重复 Token 和无效监督。

建议配图：三条横向时间轴，Action 和 Point Track 连续输出，Subtask 稀疏输出事件。

## 第 4 页：路线 A——Temporal-Depth Autoregressive Multi-stream Prediction

标题：Route A：沿时间与 Primitive 两个维度进行层次化自回归预测

这一页需要给出核心数学定义。

### 1. 从传统 VLA 到多流联合建模

传统 Action-centric VLA：

$ P(A_{1:T}\mid O,L) $

TD-VLA：

$ P(A_{1:T},P_{1:T},S_{1:T}\mid O,L) $

将三种 Primitive 组织为：

$ Z_t=(z_{t,1},z_{t,2},z_{t,3}) $

在时间维度：

$ \boxed{ P(Z_{1:T}\mid O,L) = \prod_{t=1}^{T} P(Z_t\mid Z_{<t},O,L) } $

在 Depth 维度：

$ \boxed{ P(Z_t\mid Z_{<t}) = \prod_{k=1}^{K} P(z_{t,k}\mid Z_{<t},z_{t,<k}) } $

### 2. Temporal-Depth Transformer 的分工

### 3. 两个维度的作用

- Temporal Transformer 负责时间上下文与历史记忆。
- Depth Transformer 负责同一时间窗口内的跨 Primitive 条件建模。
- 两个维度可以共享 Hidden Dimension，但承担不同的因果关系和预测任务。

本页要强调： Route A 的创新不只是增加一个 Depth Decoder，而是对多流联合概率分布进行二维因子化。

## 第 5 页：路线 A——生成顺序与 Selective Early Exit

标题：Depth Ordering：不同 Primitive 的生成顺序决定推理行为

这一页进一步解释 Route A 如何支持选择性生成。

### 1. 两种主要生成顺序

A1：Action-first

$ A\rightarrow P\rightarrow S $

对应概率分解：

$ P(A,P,S\mid C) = P(A\mid C) P(P\mid A,C) P(S\mid A,P,C) $

优势：

- 优先生成机器人可执行的动作。
- Action 生成后可以直接 Early Exit。
- 需要空间轨迹时再生成 Point Track。

A2：Task-first

$ S\rightarrow A\rightarrow P $

$ P(S,A,P\mid C) = P(S\mid C) P(A\mid S,C) P(P\mid S,A,C) $

优势：

- 先明确任务阶段。
- 任务语义可以作为动作预测的条件。
- 更适合需要实时任务状态输出的应用。

### 2. Selective Inference 机制

![image-20261112120021604](C:\Users\32775\AppData\Roaming\Typora\typora-user-images\image-20261112120021604.png)

### 3. 必须研究的关键变量

- Depth Ordering：A→P→S、S→A→P 等。
- Early Exit Position：在不同 Primitive 后停止。
- Conditional Dependence：前一个 Primitive 是否真正改善后一个 Primitive。
- Inference Cost：不同生成组合的实际延迟与 FLOPs。

## 第 6 页：路线 B——Global Multi-Primitive Parallel Drafting

标题：Route B：一次性并行预测所有 Primitive

与 Route A 不同，Route B 不要求先生成 Action 再生成 Point Track，而是直接构建一个包含所有 Primitive 的全局预测过程。

### 1. B1：Shared Global Latent + Parallel Heads

$ G=E_\theta(O,L,q) $

$ \begin{aligned} \hat A &=D_A(G)\\ \hat P &=D_P(G)\\ \hat S &=D_S(G) \end{aligned} $

特点：

- 最简单的并行预测架构。
- 三个 Decoder 可以同时执行。
- 不同输出通过共享 Global Latent 间接关联。

它是必须实现的 Baseline。

### 2. B2：Cross-Primitive Attention

构造不同 Primitive 的预测 Slot：

$ Z_{\text{mask}}= [Z_A^{mask},Z_P^{mask},Z_S^{mask}] $

共同输入非因果 Transformer：

$ H_D=T_D(H,Z_{\text{mask}}) $

再通过不同 Head 预测：

$ \begin{aligned} \hat Z_A&=Head_A(H_D)\\ \hat Z_P&=Head_P(H_D)\\ \hat Z_S&=Head_S(H_D) \end{aligned} $

特点：

- 不同 Primitive 在 Hidden Space 中双向交互。
- 比独立 Head 具有更强的跨模态建模能力。
- 一次前向即可输出全部预测。

注意：Masked Slot 之间的交互不等于已经看到了其他 Primitive 的最终采样结果，因此它属于并行联合预测近似。

### 3. B3：Iterative Parallel Refinement

第一轮：

$ Z^{(1)}=D_\theta(H,Z^{mask}) $

后续迭代：

$ \boxed{ Z^{(r+1)}=D_\theta(H,Z^{(r)}) } $

每轮同时更新所有 Primitive。

例如：

- Round 1：三个 Primitive 各自生成初步预测。
- Round 2：通过交叉注意力发现不一致并修正。
- Round 3：进一步优化动作与空间轨迹之间的关系。

| 方案 | 前向次数 | 跨流交互          | 特点       |
| ---- | -------- | ----------------- | ---------- |
| B1   | 1        | 间接              | 简单、快速 |
| B2   | 1        | Hidden Space 双向 | 联合建模   |
| B3   | R        | 预测结果迭代交互  | 一致性修正 |

本页结论：Route B 的关键研究问题不是能不能并行，而是如何在不恢复串行生成的情况下，保证不同 Primitive 之间的预测一致性。

## 第 7 页：路线 B——VFlash 启发的 Primitive Drafting

标题：从固定 Token 序列到结构化 Primitive-level Drafting

这一页专门说明 VFlash 技术如何迁移到我们的架构。

### 1. VFlash 的核心启发

VFlash 发现，Visual Primitive 有明确的结构，因此不一定需要按照普通 AR Token 顺序逐个生成。

其设计包含三个关键点：

- Boundary Alignment：预测完整 Primitive，而非任意固定长度片段。
- Position Alignment：每个预测位置具有明确的结构角色。
- One-pass Drafting：使用非因果 Drafter 并行预测整个 Primitive。

它的 Drafter 使用轻量 Transformer，并基于标注的几何 Primitive 进行训练。

### 2. 我们的扩展：Multi-Primitive Slot Layout

定义一个全局 Draft：

$ Z_{\mathrm{draft}}= [Z_A,Z_P,Z_S] $

不同 Primitive 使用不同结构：

| Primitive   | Slot 结构                | 输出         |
| ----------- | ------------------------ | ------------ |
| Action      | $N_A$ 个 Action Slot     | Action Chunk |
| Point Track | $N_P$ 个 Trajectory Slot | 关键点轨迹   |
| Subtask     | $N_S$ 个 Event Slot      | 任务事件     |

其中：

- Action Slot 可以结合 FAST、DCT-VQ 等压缩表示。
- Point Track Slot 可以结合 Trajectory VQ。
- Subtask Slot 可以使用 Event Token。

### 3. Primitive Selection 与动态 Layout

引入 Primitive Selection：

$ m=(m_A,m_P,m_S) $

其中：

$ m_k\in\{0,1\} $

通过 $m$ 决定哪些 Primitive 被实例化、哪些 Slot 被送入 Drafter。

例如：

$ m=(1,1,0) $

表示只生成 Action 和 Point Track。

## 第 8 页：路线 A 的训练机制与损失设计

标题：Training Route A：双维度自回归联合训练

这一页需要分别解释 Temporal Transformer、Depth Transformer 和各 Primitive Head 的训练目标。

### 1. Temporal Transformer 训练

Temporal Transformer 学习跨时间窗口的因果依赖：

$ \mathcal L_T = -\sum_{t=1}^{T} \log P_\theta(Z_t\mid Z_{<t},C) $

这里 $C$ 是视觉、语言和机器人状态构成的条件上下文。

### 2. Depth Transformer 训练

在每个时间窗口内部：

$ \mathcal L_D = -\sum_t\sum_k M_t^k \log P_\theta(z_{t,k}\mid Z_{<t},z_{t,<k},C) $

$M_t^k$ 用来屏蔽当前没有有效监督的 Primitive。

这样可以解决 Subtask 事件稀疏、不能每个窗口都产生真实 Token 的问题。

### 3. 不同 Primitive 的损失

Action：

如果采用离散 Token：

$ \mathcal L_A^{AR}=-\sum_i\log P(a_i\mid \cdot) $

如果采用 Flow Matching：

$ \mathcal L_A^{FM} = \mathbb E_{t,x_t,v_t} \left[ \|v_\theta(x_t,t,C)-v_t\|^2 \right] $

Point Track：

可以采用连续轨迹回归：

$ \mathcal L_P= \frac{1}{N H} \sum_{i,j} w_{ij}\|\hat p_{ij}-p_{ij}\|_2^2 $

其中 $w_{ij}$ 用于处理有效点和遮挡情况。

Subtask：

采用事件分类或自回归事件 Token 预测：

$ \mathcal L_S=-\sum_i \log P(s_i\mid \cdot) $

### 4. 总体训练目标

$ \boxed{ \mathcal L_{\mathrm{TD}} = \lambda_T\mathcal L_T +\lambda_D\mathcal L_D +\lambda_A\mathcal L_A +\lambda_P\mathcal L_P +\lambda_S\mathcal L_S } $

这里需要强调：如果 Temporal 和 Depth 都采用 AR Token 预测，那么两项损失可以在实现中合并为统一的联合 NLL，避免重复计算同一预测目标。

### 5. 训练时需要研究的机制

- Teacher Forcing：使用 Ground Truth 历史 Primitive 训练条件生成。
- Scheduled Sampling：缓解推理时前序预测误差累积。
- Sparse Event Masking：避免 Subtask PAD/HOLD 监督淹没有效事件。
- Stream Ordering Ablation：比较 Action-first 与 Task-first。
- Multi-task Loss Balancing：避免某个 Stream 主导训练。

## 第 9 页：路线 B 的训练机制与损失设计

标题：Training Route B：Global Drafting 与 Iterative Refinement

Route B 不应简单照搬 Route A 的自回归训练方式。

### 1. B1：Shared Global Latent + Parallel Heads

直接使用标注的三个 Primitive 作为监督：

$ \hat A=D_A(G),\quad \hat P=D_P(G),\quad \hat S=D_S(G) $

训练目标：

$ \mathcal L_{B1} = \lambda_A\mathcal L_A +\lambda_P\mathcal L_P +\lambda_S\mathcal L_S $

这是最直接的多头联合监督。

### 2. B2：Cross-Primitive Attention

将所有 Ground Truth Slot 转化为 Masked Input：

$ Z_{\mathrm{input}} = [\operatorname{Mask}(Z_A), \operatorname{Mask}(Z_P), \operatorname{Mask}(Z_S)] $

通过 Bidirectional Attention 预测完整的 Primitive：

$ \hat Z=D_\theta(H,Z_{\mathrm{input}}) $

损失：

$ \mathcal L_{B2} = \sum_{k\in\{A,P,S\}} \lambda_k \mathcal L_k(\hat Z_k,Z_k) $

训练时需要考虑：

- 随机 Mask 不同 Primitive。
- 随机 Mask 不同 Slot。
- 混合不同 Primitive 组合。
- 让模型适应不完整的输入条件。

### 3. B3：Iterative Parallel Refinement

第一轮预测：

$ Z^{(1)}=D_\theta(H,Z^{mask}) $

第 $r$ 轮预测：

$ Z^{(r+1)}=D_\theta(H,Z^{(r)}) $

可以采用多轮监督：

$ \boxed{ \mathcal L_{B3} = \sum_{r=1}^{R} \alpha_r \sum_k \lambda_k \mathcal L_k(Z_k^{(r)},Z_k^{*}) } $

其中 $Z_k^*$ 是 Ground Truth。

进一步可以探索：

- 随机噪声初始化。
- Confidence-based Re-masking。
- Residual Refinement。
- 不同 Primitive 的不同 Noise Schedule。

### 4. VFlash Drafting 如何训练？

可以参考 VFlash 的监督方式：

- 冻结基础 VLM，提取 Context。
- 使用真实标注的 Primitive 训练轻量 Drafter。
- 对每个 Primitive 直接监督其完整结构化输出。
- 通过固定 Slot Layout 或动态 Layout 保证位置对齐。

如果输出是离散 Token，可以采用：

$ \mathcal L_{\mathrm{draft}}^{CE} = -\sum_{k,i} M_{k,i} \log P_\theta(z_{k,i}^*\mid H) $

如果输出是连续值，则采用对应的回归或 Flow Matching 损失。

这里不需要强制 Drafter 复现某个 AR Teacher 的逐 Token 采样顺序；可以直接使用 Ground Truth Primitive 监督完整输出。这也是 VFlash 的重要启发。

### 5. 三种路线的训练差异

| 训练维度        | Route A         | B1/B2      | B3              |
| --------------- | --------------- | ---------- | --------------- |
| 时间建模        | Causal AR       | 全局条件   | 全局条件        |
| Primitive 建模  | Depth AR        | 并行预测   | 并行迭代        |

## 第 10 页：基于 π0.5 的具体扩展方案

标题：Extending π0.5 to Temporal-Depth Multi-stream VLA

我赞同将 π0.5 作为第一种代表性基础模型。

- 比较成熟的多机器人训练设计。

## 第 11 页：基于 OpenVLA-OFT 的具体扩展方案

标题：Extending OpenVLA-OFT to Multi-Primitive Parallel Prediction

我认为 OpenVLA-OFT 是另一条非常好的实现路线，尤其适合先验证 Global Drafting。

### 1. 原始架构的优势

OpenVLA-OFT 的核心改动包括：

- 保留预训练 OpenVLA Backbone。
- 在输入序列中加入空 Action Embeddings。
- 采用双向注意力预测 Action。
- 使用连续 Action Head。
- 一次前向预测整个 Action Chunk。

因此它已经具备并行 Action Chunk 解码能力。

### 2. 扩展方案

将原来的 Action Embeddings 扩展为多种 Typed Primitive Embeddings：

$ X_{\mathrm{out}} = [X_A,X_P,X_S] $

并为不同 Primitive 设置对应的预测 Head。

![image-20261112120224725](C:\Users\32775\AppData\Roaming\Typora\typora-user-images\image-20261112120224725.png)

### 3. 两种具体实现

方案 A：Global Multi-Primitive Drafting

- 所有 Primitive Slot 同时输入。
- 使用 Bidirectional Attention。
- 一次前向输出三个 Primitive。
- 可以通过 Primitive Mask 实现选择性生成。

这是最容易在 OpenVLA-OFT 上实现的路线。

方案 B：Temporal-Depth AR

- 将原始 Action Chunk 组织为多个 Temporal Step。
- 每个 Temporal Step 包含不同 Primitive Slot。
- 引入 Temporal Causal Mask。
- Depth 方向采用 Primitive-specific Causal Ordering。
- 通过生成顺序实现 Early Exit。

这条路线改造幅度更大，因为原始 OFT 的并行 Action Decoder 并不是 Temporal-Depth 双维度自回归模型。

### 4. 推荐的开发顺序

1. 复现 OpenVLA-OFT 原始 Action Chunk 性能。
2. 增加 Point Track Head。
3. 增加 Subtask Head。
4. 实现 B1 Parallel Heads。
5. 实现 B2 Cross-Primitive Attention。
6. 最后再实现 Temporal-Depth AR。

选择这两个基础模型的意义： π0.5 代表 Flow Matching Action Expert 路线，OpenVLA-OFT 代表并行连续 Action Decoder 路线。可以检验 TD-VLA 是否具有跨不同 Action Generation Paradigm 的适用性。

## 第 12 页：实验设计、研究风险与下一步计划

标题：From Architecture Design to Verifiable Research Contributions

### 1. 三个核心实验问题

RQ1：TD 架构是否带来有效的多流联合预测能力？

- 对比单序列 AR、Parallel Heads、TD-AR。
- 验证 Action、Point Track、Subtask 的预测性能。
- 比较不同 Primitive Ordering。

RQ2：Global Drafting 能否实现高效的多流并行预测？

- 比较 B1、B2、B3。
- 测试一次前向与多轮 Refinement。
- 分析不同 Primitive 之间的预测一致性。

RQ3：Selective Generation 是否真正提高推理效率？

- Action Only。
- Action + Point Track。
- Action + Subtask。
- Action + Point Track + Subtask。

比较：

- FLOPs。
- End-to-end Latency。
- Peak Memory。
- GPU Utilization。
- Action Success Rate。

### 2. 关键消融实验

| 消融变量                     | 研究目的           |
| ---------------------------- | ------------------ |
| 无 Temporal Transformer      | 验证时间建模价值   |
| 无 Depth Transformer         | 验证跨流建模价值   |
| 不同 Depth Ordering          | 验证条件生成顺序   |
| 无 Cross-Primitive Attention | 验证跨流交互价值   |
| 不同 Refinement 次数         | 验证速度—精度权衡  |
| 不同 Primitive Mask          | 验证选择性生成能力 |
| 不同 Tokenizer               | 验证表示压缩效果   |

### 3. 研究风险

- 现有工作已探索并行动作生成和 Primitive Drafting，不能把它们直接作为独立创新。
- 多流并行不一定优于顺序条件生成。
- Point Track 与 Action 的空间关系需要真实数据监督。
- Subtask 是稀疏事件，训练时需要特殊处理。
- 选择性预测需要真正减少计算，而不只是隐藏输出。
- 增加 Primitive 可能引入负迁移和额外延迟。

### 4. 实施路线

1. Phase 1：数据与 Tokenizer

   建立统一的 Action、Point Track、Subtask 数据格式和监督机制。

2. Phase 2：两个基础模型复现

   选择 π0.5 和 OpenVLA-OFT，建立可复现基线。

3. Phase 3：两条主路线实现

   分别实现 TD-AR 和 Global Multi-Primitive Drafting。

4. Phase 4：联合对比与消融

   验证并行性、选择性推理和任务性能。

5. Phase 5：进一步扩展

   再考虑 Block Diffusion、Token Compression 和异步执行。
