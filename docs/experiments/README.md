## 维护约定

- 纳入正式运行的完整训练/周期验证日志及正式闭环评测记录；不纳入短测、fixture、恢复测试、启动验收或失败调试日志。正式训练过程中的周期记录用于绘制完整曲线，不属于中间测试。
- 每份报告明确数据划分、初始化、代码版本、训练预算、统计口径、最终模型选择及局限。离线验证与闭环成功率分别记录；不同协议不直接合并比较。
- 默认报告最终检查点；如另报最佳验证检查点，明确选择规则，不悄悄替换最终权重。
- 日志保留原始数值，图像由日志生成；平滑窗口和样本数量必须标明。PNG 用于阅读，SVG 用于导出。
- 每个目录保存 `manifest.json`，记录归档文件 SHA256、原始来源和大文件定位；保留绘图入口。变更归档文件后重新计算校验清单。
- 后续评测使用独立实验目录，在训练报告或索引中关联。对照结论注明种子数、每任务回合数及实验是否具有相同预算。
