# TD-VLA v1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. 用户已授权开始实现，在当前实验分支执行，保留已有未提交文档。

**Goal:** 实现可训练、可恢复的三组模型与 v4 数据接入，并验证双卡短程运行。

**Architecture:** 复用 TurboVLA，扩展其 ACT decoder 为并行多流；全双向和分块独立仅改变 mask。共享 5 类 Stage 头，预测后按任务阶段数截断。

**Tech Stack:** Python 3.10、uv、PyTorch 2.7.1、锁定 TurboVLA、HDF5/NPZ。

**Spec:** docs/model-architecture-v1.md、docs/data/p2-annotation-rules.md。

## Global Constraints

- 冻结 BERT，其余模块联合训练；无额外历史或动作自回归。
- Action 保留上游 tanh；Track 无界，按原图坐标监督，不做随机图像几何增强。
- 仅入选 300 回合，按 episode 划分，归一化只使用训练集。
- Oracle/未来标签只作监督，不能进入输入；无效值在计算损失前排除。
- 权重初始为 Action=1、Track=0.1、Stage=0.1，独立配置，非最终 recipe。

## Review Focus

- 全无效辅助标签时损失有限、可反传，DDP 参数不意外闲置。
- 分块 mask 隔断跨流路径，全双向存在跨流梯度。
- 原始越界 Stage 输出不被截断后的指标掩盖。
- 恢复时数据/配置不一致必须报错，每个 rank 随机状态完整恢复。
- 数据按需读取，不能将 26 GB 图像全部加载为内存数组。
